# Third-party 3D assets

The six player/AI cars are real production models authored on Sketchfab,
optimized offline (`scripts/optimize-cars.mjs`: decimation, WebP textures,
rig canonicalization) and committed to `public/models/`. The optimized GLBs
are derivative works and stay under each source license below. Credit is also
surfaced in-game behind the `REAL_BRANDING` garage panel where applicable.

License notes:

- **CC-BY 4.0** — attribution (this file) satisfies the license.
- **CC-BY-NC 4.0** (`terzo.glb`) — non-commercial use only. Velocity Rush is
  distributed free of charge with no monetization; this qualifies as
  non-commercial under the license. If the game is ever monetized, remove
  `terzo.glb` (and its `CarId` catalog row) first.
- **CC-BY-SA 4.0** (`carrera.glb`) — share-alike: the derivative `carrera.glb`
  itself must remain CC-BY-SA 4.0. The rest of the game codebase is unaffected
  (the GLB is a separate work, not incorporated into a larger code artifact).

Vehicle **names** are trademarks of Nissan, Porsche AG and Lamborghini; real
names and maker badges render only when the `REAL_BRANDING` flag is on. The
game is an unofficial fan project with no affiliation or endorsement. With
the flag off, no real name or wordmark decal is attached (the optimised GLB
geometry still drives the car). The `?proc=1` kill switch goes further:
every car is rebuilt by the procedural builder — original geometry only, no
GLB asset in play. A GLB that fails its rig validation or fails to load
falls back to procedural FOR THAT CAR for the session; nothing rebuilds it
later.

All other in-game art (tracks, props, procedural cars, textures) is original
work generated by this repository's code.
